## Повторение

npm run typecheck
npm run lint
npm test
npm run test:db
npm run build
npm run test:e2e
npm run test:connected

Последняя команда временно строит тестовую конфигурацию с перехватом всех её сервисных запросов и в finally восстанавливает обычную сборку. Не запускайте её на сервере, который раздаёт out/ внешним посетителям.
