# Сайт «Антех Восток»

Корпоративный сайт производителя: публичные страницы, единый каталог продукции и услуг,
сбор нескольких позиций в заявку и закрытое управление каталогом.

## Локальный запуск

```bash
npm install
cp .env.example .env.local
npm run dev
```

Проверки перед выпуском:

```bash
npm run typecheck
npm run lint
npm test
npm run build
```

Готовая статическая версия создаётся в `out/`.

## Настройка каталога и доступа

1. Создайте проект Supabase.
2. Выполните SQL из `supabase/migrations/001_catalog.sql` в SQL Editor.
3. В Supabase Auth отключите открытую регистрацию и добавьте разрешённых пользователей вручную.
4. Для каждого редактора скопируйте UUID пользователя и выполните:

```sql
insert into public.site_admins (user_id) values ('UUID-ПОЛЬЗОВАТЕЛЯ');
```

5. Добавьте production-адрес `/admin/` в список разрешённых адресов перенаправления Auth.
6. Заполните `NEXT_PUBLIC_SUPABASE_URL` и `NEXT_PUBLIC_SUPABASE_ANON_KEY`.

Анонимный ключ Supabase является публичным. Изменение каталога защищает RLS. Service-role ключ
в сайт добавлять нельзя. Удаление позиций намеренно не разрешено.

Если Supabase ещё не подключён, публичный каталог показывает три подтверждённые анкетой категории,
а админка выводит инструкцию о настройке.

## Форма заявки

Укажите endpoint Formspree в `NEXT_PUBLIC_FORM_ENDPOINT`. До этого форма валидирует данные,
но ничего не отправляет и честно сообщает о демонстрационном режиме. Пароль от почты не нужен.

Поскольку переменные `NEXT_PUBLIC_*` встраиваются в статическую сборку, после их изменения сайт
нужно пересобрать.

## Размещение

Сайт раздаётся Nginx-контейнером. Пример конфигурации лежит в `deploy/`.

1. Скопируйте `deploy/.env.example` в `deploy/.env` и укажите домен и каталог релизов.
2. Получите сертификат Let's Encrypt для домена.
3. Соберите проект и загрузите содержимое `out/` в новый каталог `releases/<дата-время>`.
4. Атомарно переключите ссылку `current` на новый релиз.
5. Запустите `docker compose --env-file .env up -d` в каталоге `deploy/`.

До запуска обязательно замените все явно обозначенные временные сведения, заполните политику
обработки данных и установите `NEXT_PUBLIC_SITE_URL`.
