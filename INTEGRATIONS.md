# Подключение почты и каталога

## Готово и что ещё требуется

SMTP-отправка подготовлена и проверена на локальном приёмнике. Для реальной доставки нужны параметры почтового сервиса. Docker в текущем окружении отсутствует; контейнерный запуск ещё не проверен. Каталог работает из файла без внешнего сервиса.

## SMTP

1. Скопировать `.env.server.example` в `.env.server` в корне. Заполнить `SMTP_HOST`, `SMTP_PORT` (465 или 587), `SMTP_USER`, `SMTP_PASS`, `MAIL_FROM`, `MAIL_TO`. Последние два могут совпадать. Использовать отдельный пароль приложения, если его поддерживает почтовый сервис. `SITE_ORIGIN` — точный origin сайта, без завершающего `/`.
2. Секреты не добавлять в `NEXT_PUBLIC_*`, Git и статическую сборку. Сертификат SMTP проверяется; TLS обязателен. Для проверки конфигурации можно запустить `npm run start:api`. Без SMTP запросы получают 503, успешная отправка не имитируется.
3. Для выпуска: настроить `deploy/.env` с SITE_DOMAIN и STATIC_ROOT; сертификаты и статический релиз подготовить по существующему Nginx-конфигу. Из deploy запустить `docker compose --env-file .env --env-file ../.env.server up -d --build`. API доступен только во внутренней сети Compose. Конфигурация контейнера подготовлена, Docker-сборка здесь не выполнялась.
4. В окружении сборки сайта установить `NEXT_PUBLIC_FORM_ENDPOINT=/api/request`, затем `npm run build`. Перед включением согласовать обработку данных. Для отката отключить endpoint и пересобрать статический сайт.
5. После подключения отправить согласованную тестовую заявку и проверить её получение, включая папку спама, кодировку, состав, исполнение, длину и контакт. Сам факт принятия письма SMTP-сервером ещё не доказывает попадание во входящие.

Ограничения: не больше 5 попыток за 10 минут с одного IP, тело до 64 KiB, фиксированный получатель, проверка Origin и согласия, honeypot. Прокси заменяет X-Real-IP, прямой доступ к API запрещён. Один API-процесс; ограничения и отпечатки повторов хранятся в памяти 10 минут, сбрасываются при рестарте. После ошибки SMTP автоматического повтора нет; при обрыве после принятия письма повторная ручная отправка может дать дубль. Очереди писем и гарантии exactly-once нет.

## Каталог

По решению пользователя от 9 октября Supabase не используется. Каталог до 100 позиций хранится в `content/catalog.json` и обновляется с выпуском сайта. Подключение базы, учётные записи редакторов и пароли доступа к каталогу не нужны. Порядок изменения данных — в README.md.
